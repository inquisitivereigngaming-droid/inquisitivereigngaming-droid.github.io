Privacy Policy

Last updated: November 24, 2026

Twitch VOD Pipeline ("the app") is a personal tool run by its owner on their own computer. It is used only to manage the owner's own YouTube channel. It is not offered to the public.

Data the app accesses

  • Permission to upload videos and set thumbnails on the owner's YouTube channel.
  • Read-only statistics (views, likes) for videos the app uploaded to that channel.

How data is stored

The OAuth token Google issues is stored only in a local file on the owner's computer. Video statistics are stored in a local log file on the same computer, used to improve future uploads. Nothing is stored on any external server run by the app.

Sharing

The app does not sell, share, or transfer Google user data to anyone. It does not use Google user data for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google Account → Third-party connections.

Contact

Questions can be raised through the owner's GitHub profile: github.com/inquisitivereigngaming-droid.
